CENC helper for Cloudflare Workers.

This package copies the progressive-MP4 CENC AES-CTR parser from xiaobei206/beixiaoguo-web/internal/cenc at commit e7ebd847b8a2f824726ad293ccfec03c4750abd9. It supports the MP4 sample layout formats covered by that parser. HLS/DASH and other DRM schemes are not implemented.
